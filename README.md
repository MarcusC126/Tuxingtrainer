# Tuxingtrainer · 图形推理训练器

面向公务员行测图形推理的 Chrome/Edge 浏览器侧栏训练扩展，通过“观察特征—关联考点—验证规律—排除选项”的双栏交互，帮助用户建立系统的解题思路。支持专题提示、候选考点排序、本地进度保存和思考路径复盘。

## 功能说明

这是一个 Chrome / Edge Manifest V3 Side Panel 扩展。它将图形推理的训练过程拆成两端：

- 左侧只记录肉眼可见的观察事实，支持多选。
- 右侧将关联考点按专题与排除成本排序，支持未检、暂留、排除、确认。
- 点击右侧考点会反向高亮左侧可回看的观察证据。
- 会话通过 `chrome.storage.local` 保存，底部可手动选择最终考点并复盘观察遗漏、映射遗漏或验证错误。

## 加载

先在仓库页面点击 **Code → Download ZIP** 并解压，然后：

1. 打开 Chrome 或 Edge 的扩展管理页，开启“开发者模式”。
2. 选择“加载已解压的扩展程序”。
3. 选择解压后的项目目录（其中应包含 `manifest.json`）。
4. 点击扩展图标打开 Side Panel。

扩展不请求网页读取权限，也不会自动识图、OCR 或猜答案。

## 验证

运行 `node tests/knowledge-integrity.test.js` 可检查 canonical ID 唯一性、双向边、专题引用与五个专题触发场景。
